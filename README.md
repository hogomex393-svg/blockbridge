# BlockBridge

A playful block-based coding tool for learning eight introductory concepts and transferring blocks to JavaScript.

Website: https://hogomex393-svg.github.io/blockbridge/

Open index.html locally or use GitHub Pages. The standalone page embeds the scripts, style, illustrations and font. It runs without external dependencies.
